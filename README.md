# Night of Fright

A VR game built in Unity for the Oculus, made with a small team for a game development class at UCF.

You fight off ghosts with your flashlight while solving a puzzle: the correct code is written on the door, and you have to enter it on the keypad. Type the right code and you win.

## Design goals

We wanted a tense, spooky atmosphere that isn't actually frightening, with enough challenge to make the player stop and think. Combining the combat with a puzzle was how we tried to do both.

## Built with

- Unity
- C#
- Oculus (VR)

## Running it

This repo is here for reference. The project was built for the Oculus and isn't set up to run outside that environment.
